- Use fictional bot names and data (not real user accounts)
- Show the dark theme (it's the default and looks best in stores)
- Include brief text overlays explaining each screen
- Keep text overlays to 3-5 words max
- Match the app's actual UI — no mockups that don't reflect real screens
- Show the most impressive/unique features first
